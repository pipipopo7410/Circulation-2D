# 血液循環平面網站（GitHub 上傳版）

這是目前可運作的 V1 三模式互動網站，不是尚未整合的 V2 SVG 研究稿。

## GitHub Pages 上傳方式
1. 解壓縮此 ZIP。
2. 進入解壓縮後資料夾，全選裡面的 8 個檔案，直接上傳到 GitHub Repository 的根目錄。不要上傳外層資料夾本身。
3. Settings → Pages → Deploy from a branch → main → /(root)。
4. 公開後以 GitHub Pages 網址開啟（不要用本機 file:// 測試離線快取）。

必備檔案：index.html、styles.css、app.js、circulation.svg、sw.js、manifest.webmanifest、favicon.svg。

注意：V2 SVG 主圖目前只有審查稿，未替換 V1 的主站。本版尚未完成 iPad Safari 實機／全畫面無捲動驗收，正式課堂使用前應先測試。
